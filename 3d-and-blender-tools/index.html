About this tool

A small tool in the same spirit as the rest of Pink Bourbon Estate: free, readable, and yours. Everything stays in this browser and nothing is sent anywhere; you can download your lists as Markdown text or as CSV spreadsheet files. It comes empty: it holds only what you type, and it does not recommend, rate or sell anything. The code is plain JavaScript with comments, in this folder. This is a work in progress, not all tools are actively maintained, and nothing here is professional advice.

Pink Bourbon Estate is a small place for free, open, readable tools. No cookies, no tracking, no adverts, nothing loaded from other sites.

All tools here are works in progress: expect bugs, and not every one is actively maintained.
