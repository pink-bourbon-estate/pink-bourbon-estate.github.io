Play: the Template sandbox

The lessons below are for learning to write the code. Template is for playing with the result: a sandbox where you build a page or a whole site from panels, with no code needed (and a Code view when you want to learn by reading it).

  • Play and edit. Start from a page, a document, a website or a tool plan. Click text to type in it, drag panels, change widths, switch between Boxes and Code.
  • Download one page (.html) for a document or a page you will open, print or interact with yourself.
  • Download site folder (.zip) for a project you want on GitHub: unzip it, upload the files to a new repository and switch on Pages (the README inside says how). Projects come with the four standard tabs: Sources, My Data, Example Data and FAQ.

Connecting your data to a chart. Charts do not fetch anything; you give them the numbers. In a tracker tool, open My Data and download the CSV. Open it in any spreadsheet, copy two columns, and paste them into the chart's Data box in Template, one pair per line as label, number (for a scatter plot, x, y; for a histogram, numbers separated by spaces). The chart redraws as you type. Choose the chart type (bar, line, pie, histogram, box plot and more) from the panel list on the left.
