Video Editing Toolkit

Three small jobs that come up all the time, in one program: shrink a video, pull out its audio, or save a still every few seconds named by the time it was taken. A window you can drop folders onto, and a command line for scripts. Free, no account, and your videos never leave your computer.

Work in progress, and an honest note: the desktop app is in the Toolkits repository. It is a careful wrapper around ffmpeg, which you install once (it is not bundled). The engine and command line have been tested against real video; the window and the Windows build are built automatically but have had less hands-on testing. The demo page here is a demonstration in your browser, not the app.

1. Try the demo

Pick a video or make a sample, pull frames out by time, extract the audio, and see what compression does. Each job shows the exact ffmpeg command the app would run.

2. Get the app

Windows and Linux downloads are on the Toolkits Releases page (video-editing-toolkit-v0.1.N). It installs for you only, with no admin rights, and updates itself with a checksum check.

What it does

Compress: H.265 or H.264 into an MP4, with a quality setting, a size cap, and an option to replace the original only when the new file is smaller. Extract audio: mp3, m4a, aac, opus or wav, optionally mono. Extract frames: a still every N seconds as JPEG or PNG, named like lecture_t00m10s.jpg, with an option to skip frames that look the same (slides). All three take files or whole folders.

Better than the scripts it replaces

It replaces three small Python scripts. Frame times are now correct: the old method returned the frame nearest the middle of each period, so "every 10 seconds" gave frames at about 5, 15 and 25 seconds, with the wrong names. H.265 files are tagged so QuickTime and iPhone play them. Output is always a format every player accepts. Videos with no audio, or with extra data tracks, no longer fail. Replacing an original is verified first. There is a progress bar, a Cancel button, and ffmpeg's own message when something goes wrong.
